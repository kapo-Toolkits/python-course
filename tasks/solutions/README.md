# სანიმუშო ამოხსნები

[`../practical-assignments.md`](../practical-assignments.md)-ის ხუთივე დავალების
საცნობარო ამოხსნა. თითოეული ფაილი **ნამდვილად გაშვებულია** და ავტომატურად მოწმდება.

ამოხსნები დაწერილია იმ დონეზე, რომელიც შესაბამის კვირაზეა გავლილი:
დავალება #1 ფუნქციების გარეშეა (III კვირაზე ისინი ჯერ არ იცის სტუდენტმა),
#2-დან კი — ფუნქციებით, docstring-ებით და `if __name__ == "__main__":` ბლოკით.

## შემოწმება

```bash
python test_solutions.py
```

19 ტესტი — მათ შორის კიდურა შემთხვევები (`stats()`, `is_prime(0)`,
ცარიელი ტექსტი, არარსებული ფაილი) და docstring-ების 23 `>>>` მაგალითი.
`pytest`-იც მუშაობს, თუ დაყენებული გაქვს:

```bash
pytest --doctest-modules
```

## ⚠ სანამ სემესტრს დაიწყებ

ეს რეპოზიტორი **საჯაროა** — ამოხსნები სტუდენტისთვისაც ხელმისაწვდომია.
დავალებები კი აუდიტორიაში სრულდება და ქულა ისმება. ორი გამოსავალია:

1. **სემესტრიდან სემესტრში შეცვალე ციფრები და მონაცემები** — ბილეთის ფასი,
   შეფასების ზღვრები, ტექსტი, სტუდენტების სია. ლოგიკა იგივე რჩება,
   კოპირება კი აზრს კარგავს. ყველაზე მარტივი გზაა.
2. **გადაიტანე `solutions/` ცალკე, დახურულ რეპოზიტორში** — თუ დავალებები
   უცვლელი გინდა.

მესამე ვარიანტიც არსებობს: ამოხსნები **გასწორების შემდეგ** გაუზიარე
სტუდენტებს, როგორც სასწავლო მასალა — „ტიპური შეცდომების“ ბლოკებთან ერთად
ისინი კარგი უკუკავშირია. არჩევანი შენია.
