# პროგრამირების საწყისები (Python) — სალექციო პრეზენტაციები

ღია სასწავლო მასალა — 15-კვირიანი შესავალი კურსის 16 პრეზენტაცია
(15 კვირა + სამუშაო გარემოს მომზადების ცალკე დეკი).

არ არის მიბმული არც უნივერსიტეტზე, არც კონკრეტულ პროგრამაზე, არც ინსტრუმენტზე:
შეფასების სქემები სარეკომენდაციოა, ბრენდირება არსად არაა, და მასალა თავისუფლად
გამოიყენება, გადაკეთდება და გავრცელდება.

**გახსენი [`index.html`](index.html)** — იქიდან ყველა ლექციაზე გადახვალ.

## რედაქტირება

### ახალი სლაიდი

დაამატე `<section class="slide">` სასურველ ადგილას — მეტი არაფერი, ნუმერაცია ავტომატურია.

```html
<section class="slide">
  <p class="kicker">რუბრიკა</p>
  <h2>სათაური</h2>
  <ul class="pts">
    <li><b>მთავარი</b><small>განმარტება</small></li>
  </ul>
  <div class="note">ლექტორის ჩანაწერი — ჩანს მხოლოდ N-ზე</div>
</section>
```

### მზა კომპონენტები

| კლასი | რისთვის |
|---|---|
| `.kicker` | პატარა რუბრიკა სათაურის ზემოთ |
| `.lead` `.big` `.small` `.muted` | ტექსტის ზომები |
| `ul.pts` / `ol.pts` | სიები; `<small>` შიგნით — ქვე-ხაზი |
| `.grid` / `.card` | ბარათების ბადე |
| `.two` | ორი სვეტი |
| `pre.code > code` | კოდი — **სინტაქსი ავტომატურად ფერდება** |
| `pre.code[data-title]` | ჭდე კოდის კუთხეში |
| `.out` | პროგრამის გამოტანა (ტერმინალის ხედი) |
| `.callout` `.tip` `.warn` `.err` | ხაზგასმული ბლოკები |
| `.quiz > details` | კითხვა დაკეცილი პასუხით |
| `.note` | ლექტორის ჩანაწერი |
| `code.inl` · `kbd` · `.tag` | ტექსტში ჩართული ელემენტები |

### ფერების შეცვლა

`assets/deck.css`-ის პირველი 40 ხაზი — სხვაგან ფერი არსად წერია.

```css
:root{
  --accent:  #2b6cb0;   /* მთავარი აქცენტი */
  --accent2: #2f855a;   /* პასუხები, „კარგი“ */
  --bg: #fdfdfc;  --ink: #1b1b19;
}
```

მუქი თემა — იმავე ფაილში, `[data-theme="dark"]` ბლოკში.

### კოდის ხაზგასმა

`<pre class="code"><code>` შიგნით Python ავტომატურად ფერდება.
თუ ხაზგასმა არ გინდა (ტერმინალის გამოტანა, სხვა ენა) — `<code class="nohl">`.

> ⚠ HTML-ში `<` და `>` კოდის შიგნით უნდა დაიწეროს როგორც `&lt;` და `&gt;`.

## PDF / დარიგება

ნებისმიერ პრეზენტაციაში `P` (ან <kbd>Ctrl</kbd>+<kbd>P</kbd>) → *Save as PDF*.
ბეჭდვის რეჟიმში ყველა სლაიდი ცალკე გვერდზეა და **ლექტორის ჩანაწერებიც ჩანს** —
ანუ ერთი და იგივე ფაილიდან იღებ ორივეს: საპრეზენტაციო ეკრანსაც და დარიგებასაც.

## ლოკალური სერვერი (არასავალდებულო)

ფაილები `file://`-იდანაც მუშაობს. თუ სერვერი გირჩევნია:

```bash
python -m http.server 8899
```

შემდეგ გახსენი `http://localhost:8899/`.
