შემოწმება — 9 კითხვა

1. რა განსხვავებაა "w" და "a" რეჟიმებს შორის?
"w" ფაილის შიგთავსს შლის და ახლიდან წერს; "a" არსებულს ინახავს და ბოლოში ამატებს.
2. რატომ ვწერთ encoding="utf-8"?
Windows-ზე ნაგულისხმევი კოდირება UTF-8 არაა, ამიტომ ქართული ტექსტი ან „კუბიკებად“ გამოჩნდება, ან UnicodeDecodeError-ს გამოიწვევს.
3. რა უპირატესობა აქვს with open(...) as f:-ს?
ფაილს ავტომატურად ხურავს ბლოკიდან გამოსვლისას — მაშინაც კი, თუ შიგნით შეცდომა მოხდა.
4. რას დაბეჭდავს? a = [1,2]; b = a; b.append(3); print(a)
[1, 2, 3]. b = a ასლს არ ქმნის — ორივე სახელი ერთსა და იმავე სიაზე მიუთითებს. ასლისთვის: a.copy() ან a[:].
5. რას აბრუნებს lst.sort()?
None — ის ორიგინალს ცვლის ადგილზე. ახალი დახარისხებული სიისთვის — sorted(lst).
6. რა განსხვავებაა append([3,4])-სა და extend([3,4])-ს შორის?
append მთელ სიას ერთ ელემენტად დაამატებს → [1,2,[3,4]]; extend ელემენტებს ცალ-ცალკე → [1,2,3,4].
7. რით განსხვავდება tuple list-ისგან?
tuple უცვლელია — შექმნის შემდეგ ელემენტს ვერ შეცვლი/დაამატებ. სამაგიეროდ ოდნავ სწრაფია და ლექსიკონის გასაღებად გამოდგება.
8. რას აკეთებს enumerate() და zip()?
enumerate ერთდროულად აბრუნებს ინდექსსა და მნიშვნელობას; zip ორ (ან მეტ) თანმიმდევრობას პარალელურად გადის, წყვილებად.
9. რატომ არის [[0]*3]*3 საშიში?
ის სამ მიმართვას ერთსა და იმავე სიაზე ქმნის — ერთი ელემენტის შეცვლა სამივე „რიგს“ შეცვლის. სწორია: [[0]*3 for _ in range(3)].

წვდომა — [] თუ get()?

student = {"name": "ნინო", "score": 92}

print(student.get("email"))            # None — შეცდომის გარეშე

გავლა ლექსიკონზე

scores = {"ნინო": 92, "გიორგი": 78, "ანა": 85}

print(scores.keys())     # dict_keys(['ნინო', 'გიორგი', 'ანა'])
print(scores.values())   # dict_values([92, 78, 85])
print(scores.items())    # dict_items([('ნინო', 92), ...])

# მხოლოდ გასაღებები (ნაგულისხმევი)
for name in scores:
    print(name, scores[name])

# მხოლოდ მნიშვნელობები
for score in scores.values():
    print(score)

# ✓ ორივე ერთად — ყველაზე ხშირი
for name, score in scores.items():
    print(f"{name:<10}{score:>5}")

print(sum(scores.values()) / len(scores))     # საშუალო
print(max(scores, key=scores.get))            # საუკეთესო სტუდენტი
.items()ესაა ლექსიკონზე გავლის სტანდარტული ხერხი — თითოეულ ბიჯზე tuple-ს აბრუნებს, რომელიც პირდაპირ ორ ცვლადად იშლება.

შაბლონი

სიხშირის დათვლა — ლექსიკონის კლასიკა

text = "პროგრამირება პითონზე"
freq = {}

for ch in text:
    if ch == " ":
        continue
    if ch in freq:
        freq[ch] += 1
    else:
        freq[ch] = 1

# იგივე, უფრო მოკლედ:
for ch in text.replace(" ", ""):
    freq[ch] = freq.get(ch, 0) + 1

# დახარისხება სიხშირით
for ch, n in sorted(freq.items(), key=lambda p: p[1], reverse=True):
    print(f"{ch}: {'█' * n} {n}")
მზა ინსტრუმენტი 
from collections import Counter

freq = Counter(text.replace(" ", ""))
print(freq.most_common(3))    # 3 ყველაზე ხშირი
ეს ამოცანა თითქმის ყოველთვის ხვდება დასკვნით გამოცდაზე. სთხოვე ჯერ ხელით დაწერონ, მერე Counter-ით.

    scores = info["scores"]
    avg = sum(scores) / len(scores)
    print(f"{name:<10}{info['age']:>4}{avg:>8.1f}")

# სია ლექსიკონებისგან — ყველაზე გავრცელებული ფორმა
group = [
    {"name": "ნინო", "score": 92},
    {"name": "გიორგი", "score": 78},

for s in group:
    print(s["name"], s["score"])

best = max(group, key=lambda s: s["score"])
