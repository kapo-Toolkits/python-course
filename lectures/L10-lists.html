სტუდენტების უწყისი

students = []          # სია tuple-ებისგან


def add(name, score):
    students.append((name, score))


def report():
    if not students:
        print("სია ცარიელია")
        return

    ranked = sorted(students, key=lambda s: s[1], reverse=True)
    scores = [s[1] for s in ranked]

    print(f"\n{'#':<4}{'სახელი':<15}{'ქულა':>6}")
    print("-" * 25)
    for i, (name, score) in enumerate(ranked, start=1):
        print(f"{i:<4}{name:<15}{score:>6}")

    print("-" * 25)
    print(f"საშუალო: {sum(scores) / len(scores):.2f}")
    print(f"უმაღლესი: {max(scores)} · უმდაბლესი: {min(scores)}")
    print(f"ჩააბარა: {len([s for s in scores if s >= 51])}")


add("ნინო", 92)
add("გიორგი", 78)
add("ანა", 85)
add("ლევანი", 45)
report()

შემაჯამებელი

რა უნდა დაგამახსოვრდეს

  • list — ცვალებადი, tuple — უცვლელი; ორივე დალაგებულია და ინდექსით მუშაობს
  • დამატება: append (ერთი) · extend (რამდენიმე) · insert (პოზიციაზე)
  • წაშლა: remove (მნიშვნელობით) · pop (ინდექსით, აბრუნებს) · del · clear
  • sort() ცვლის და აბრუნებს None-ს; sorted() ახალ სიას აბრუნებს
  • b = a ასლს არ ქმნის — გამოიყენე a.copy() ან a[:]
  • [x for x in ... if ...] · enumerate() · zip()
სახლში1) სიიდან დუბლიკატების მოშორება (set-ის გარეშე). 2) ორი სიის შერწყმა და დახარისხება. 3) მატრიცის ტრანსპონირება. 4) ფაილიდან რიცხვების წაკითხვა სიაში და სტატისტიკის გამოტანა.
