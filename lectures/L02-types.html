თავისებურება

Python დინამიკურად ტიპიზებულია

ტიპს არ ვწერთ — Python მას თავად ცნობს მინიჭებული მნიშვნელობიდან.

x = 10          # int
x = "ტექსტი"    # ახლა str
x = 3.5         # ახლა float

ერთი და იმავე ცვლადის ტიპი პროგრამის მსვლელობისას იცვლება.

int x = 10;
x = "ტექსტი";   // შეცდომა!

იქ ტიპი ერთხელ ცხადდება და აღარ იცვლება.

თავისუფლების ფასიმოქნილობა მოსახერხებელია, მაგრამ შეცდომა მხოლოდ გაშვების დროს ჩნდება. ამიტომაა Pylance სასარგებლო — ის ბევრ ასეთ პრობლემას წერისასვე ხედავს.
კარგი კითხვაა აუდიტორიისთვის: „რა უპირატესობა და რა საფრთხე აქვს ამას?“ — მსჯელობა 3–4 წუთი.

type() — რა ტიპისაა?

a = 5
b = 5.0
c = "5"
d = True

რატომაა მნიშვნელოვანი?უმეტესი შეცდომა დამწყებთან ტიპების არევიდან იბადება: "5" + 5 → TypeError. როცა გაუგებრობაა — დაბეჭდე type().

big = 2 ** 100

# 1267650600228229401496703205376

float — სიზუსტის ზღვარი

print(0.1 + 0.2)
# 0.30000000000000004

print(0.1 + 0.2 == 0.3)   # False
print(round(0.1 + 0.2, 2) == 0.3)  # True
ეს არაა Python-ის ბაგიორობით სისტემაში 0.1 ზუსტად ვერ ჩაიწერება — ისევე, როგორც ათობითში 1/3. ეს ყველა ენას ეხება. ფულთან მუშაობისას იყენებენ decimal მოდულს ან მთელ თეთრებს.
ეს დემონსტრაცია REPL-ში აუცილებლად აჩვენე — ყოველთვის აოცებს და კარგად ამახსოვრდებათ.

კლასიკური ხაფანგიbool("False") არის True, რადგან ეს არაცარიელი ტექსტია, არა ლოგიკური მნიშვნელობა.

წესი

ოპერაციების პრიორიტეტი

  1. ( ) — ფრჩხილები
  2. ** — ახარისხება (მარჯვნიდან მარცხნივ)
  3. -x — უნარული მინუსი
  4. * / // % — მარცხნიდან მარჯვნივ
  5. + - — მარცხნიდან მარჯვნივ
print(2 + 3 * 4)        # 14, არა 20
print((2 + 3) * 4)      # 20
print(2 ** 3 ** 2)      # 512  (2 ** 9), არა 64
print(-2 ** 2)          # -4   (ჯერ 2**2, მერე მინუსი)
print((-2) ** 2)        # 4
რჩევაეჭვის შემთხვევაში დასვი ფრჩხილები. ისინი უფასოა და კოდს კითხვადს ხდის.

გამოტანა

f-სტრიქონი — თანამედროვე ფორმატირება

name = "ნინო"
score = 87.6543

# ძველი გზები
print("სტუდენტი " + name + ", ქულა " + str(score))
print("სტუდენტი {}, ქულა {}".format(name, score))

# f-სტრიქონი — ყველაზე მოხერხებული
print(f"სტუდენტი {name}, ქულა {score}")

# ფორმატირება პირდაპირ შიგნით
print(f"ქულა: {score:.2f}")        # 87.65
print(f"გამოთვლა: {2 + 3 * 4}")    # 14
print(f"{name!r}")                  # 'ნინო'
დაიმახსოვრეf ბრჭყალის წინ, ცვლადი — ფიგურულ ფრჩხილებში. დეტალურად ფორმატირებას VII კვირაზე გავივლით.

# პროგრამა ითვლის შენაძენის ღირებულებას ფასდაკლებით

print("=== კალკულატორი ===")

item = input("პროდუქტი: ")

შემაჯამებელი

რა უნდა დაგამახსოვრდეს

  • ცვლადს ტიპს არ ვუთითებთ — Python მას მინიჭებისას განსაზღვრავს
  • საბაზისო ტიპები: int · float · str · bool · None, შემოწმება — type()
  • / ყოველთვის float-ს აბრუნებს; მთელი გაყოფა — //, ნაშთი — %
  • input() ყოველთვის str-ს აბრუნებს → შემოახვიე int() ან float()
  • გამოტანისთვის — f"..." და {value:.2f}
სახლში1) წამების → სთ/წთ/წმ გადამყვანი. 2) წრეწირის სიგრძე და წრის ფართობი რადიუსით. 3) ორნიშნა რიცხვის ციფრების ჯამი (// და %-ით). 4) ტემპერატურა °C → °F.
შემდეგი — ლექცია 03შედარებისა და ლოგიკური ოპერატორები, if / elif / else + პრაქტიკული დავალება #1.
