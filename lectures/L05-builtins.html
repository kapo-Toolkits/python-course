გამეორება · ლექციები 03–04

შემოწმება — 8 კითხვა

1. რა განსხვავებაა =-სა და ==-ს შორის?
= — მინიჭება (მარჯვენა მნიშვნელობას მარცხენა სახელს აბამს), == — შედარება, აბრუნებს True/False.
2. რას დაბეჭდავს? print(True or False and False)
True. and-ის პრიორიტეტი or-ზე მაღალია, ამიტომ ჯერ False and False → False, შემდეგ True or False → True.
3. რამდენ ბიჯს გაივლის for i in range(1, 10, 3) და რა მნიშვნელობებით?
3 ბიჯს: 1, 4, 7. 10 არ შედის.
4. რა განსხვავებაა break-სა და continue-ს შორის?
break ციკლს მთლიანად წყვეტს; continue მხოლოდ მიმდინარე ბიჯს ტოვებს და შემდეგზე გადადის.
5. როდის სრულდება else, რომელიც for-ს მიება?
მაშინ, როცა ციკლი break-ის გარეშე დასრულდა ბოლომდე. თუ break გასრულდა — else გამოტოვდება.
6. რატომ არის ეს ციკლი უსასრულო?
i = 0
while i < 5: print(i)
აკლია ცვლილება: i += 1. პირობა i < 5 სამუდამოდ ჭეშმარიტი რჩება. გაჩერება — Ctrl+C.
7. რას დაბეჭდავს? x = 15; print(10 < x < 20)
True. Python უშვებს ჯაჭვურ შედარებას — ტოლფასია 10 < x and x < 20-ისა.
8. რას აკეთებს n % 10 და n // 10 ერთად, ციკლში?
n % 10 გამოყოფს ბოლო ციფრს, n // 10 კი აშორებს მას. ერთად — რიცხვის ციფრებზე გავლის სტანდარტული ხერხია.

მოდული

math — მათემატიკური ფუნქციები

import math

print(math.sqrt(16))        # 4.0     კვადრატული ფესვი
print(math.ceil(4.1))       # 5       ზემოთ დამრგვალება
print(math.floor(4.9))      # 4       ქვემოთ დამრგვალება
print(math.trunc(-4.9))     # -4      წილადის მოკვეცა
print(math.factorial(5))    # 120     ფაქტორიალი
print(math.gcd(12, 18))     # 6       უდიდესი საერთო გამყოფი

print(math.pi)              # 3.141592653589793
print(math.e)               # 2.718281828459045

print(math.log(100, 10))    # 2.0     ლოგარითმი
print(math.log10(1000))     # 3.0
print(math.exp(1))          # 2.718…
რატომ არაა ეს ჩაშენებული?ენის „ბირთვი“ მინიმალურია. სპეციალიზებული ფუნქციები მოდულებშია — იტვირთება მხოლოდ საჭიროებისას. ეს Python-ის დიზაინის პრინციპია.

მოდული

math — ტრიგონომეტრია და გრადუსები

import math

# ტრიგონომეტრიული ფუნქციები რადიანებში მუშაობს!
angle_deg = 90
angle_rad = math.radians(angle_deg)

print(math.sin(angle_rad))       # 1.0
print(math.cos(0))               # 1.0
print(math.degrees(math.pi))     # 180.0

# წრეწირის სიგრძე და ფართობი
r = 5
print(f"სიგრძე:  {2 * math.pi * r:.2f}")
print(f"ფართობი: {math.pi * r ** 2:.2f}")

# მანძილი ორ წერტილს შორის
print(math.hypot(3, 4))          # 5.0
print(math.dist((0, 0), (3, 4))) # 5.0
ტიპური შეცდომაmath.sin(90) არ იძლევა 1-ს — 90 რადიანად აღიქმება. ჯერ math.radians(90).

# 1. მთელი მოდული — ყველაზე გავრცელებული და ცხადი
import math
print(math.sqrt(16))

# 3. მოკლე ფსევდონიმი

მოდული

random — შემთხვევითი რიცხვები

import random

print(random.random())          # 0.0 ≤ x < 1.0
print(random.randint(1, 6))     # 1..6 — ორივე კიდე შედის!
print(random.randrange(0, 10, 2))  # 0,2,4,6,8

print(random.uniform(1.5, 3.5)) # წილადი დიაპაზონში

colors = ["წითელი", "მწვანე", "ლურჯი"]
print(random.choice(colors))         # ერთი ელემენტი
print(random.sample(colors, 2))      # ორი, გამეორების გარეშე

random.shuffle(colors)               # არევა ადგილზე
print(colors)
randint vs rangerandom.randint(1, 6) — 6 შედის. range(1, 6) — 6 არ შედის. ეს განსხვავება ხშირად ავიწყდებათ.

თეორია

ფსევდო-შემთხვევითობა

კომპიუტერს „ნამდვილი“ შემთხვევითობა არ შეუძლია — ის ალგორითმით ითვლის მიმდევრობას, რომელიც შემთხვევითს ჰგავს.

import random

random.seed(42)
print(random.randint(1, 100))   # 82
print(random.randint(1, 100))   # 15

random.seed(42)                  # იმავე წერტილიდან
print(random.randint(1, 100))   # 82 — იგივე!
print(random.randint(1, 100))   # 15
რატომაა სასარგებლოseed()-ით შედეგი განმეორებადია — ტესტირებისა და ლაბორატორიული სამუშაოსთვის აუცილებელია.
უსაფრთხოებაპაროლების ან კრიპტოგრაფიული გასაღებებისთვის random არ ვარგა — მისთვის secrets მოდულია.

პრაქტიკა

თამაში — გამოიცანი რიცხვი

import random

secret = random.randint(1, 100)
attempts = 0

print("გამოიცანი რიცხვი 1-დან 100-მდე")

while True:
    guess = int(input("შენი ვარიანტი: "))
    attempts += 1

    if guess < secret:
        print("მეტია ↑")
    elif guess > secret:
        print("ნაკლებია ↓")
    else:
        print(f"სწორია! {attempts} ცდაში გამოიცანი")
        break
განვითარებადაუმატე ცდების ლიმიტი (7), შეყვანის შემოწმება, ან შეაბრუნე როლები — კომპიუტერი იცნობს შენს რიცხვს ბინარული ძებნით.
ეს დავალება მუშაობს კარგად: სწრაფად იწერება, მაშინვე „თამაშად“ იქცევა. 7 ცდაში 100-მდე რიცხვის გამოცნობა ყოველთვის შესაძლებელია — კარგი შესავალი ალგორითმის ეფექტურობაში.
