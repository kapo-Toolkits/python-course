პრაქტიკა

რიცხვის ციფრებთან მუშაობა

n = int(input("მთელი რიცხვი: "))
n = abs(n)

total = 0
count = 0
reversed_num = 0

while n > 0:
    digit = n % 10          # ბოლო ციფრი
    total += digit
    count += 1
    reversed_num = reversed_num * 10 + digit
    n = n // 10             # ბოლო ციფრს ვაშორებთ

print("ციფრების ჯამი:", total)
print("ციფრების რაოდენობა:", count)
print("შებრუნებული:", reversed_num)

შემაჯამებელი

რა უნდა დაგამახსოვრდეს

  • for — ცნობილი რაოდენობა ან გავლა თანმიმდევრობაზე; while — პირობით მართვა
  • range(start, stop, step) — stop არ შედის
  • break წყვეტს, continue ტოვებს ბიჯს, else სრულდება break-ის გარეშე დასრულებისას
  • დაგროვების შაბლონი: ცვლადი ციკლამდე, ცვლილება ციკლში
  • ჩადგმულ ციკლში გარე ბიჯზე შიდა მთლიანად გადის
სახლში1) 1–100 რიცხვების ჯამი და საშუალო. 2) ფაქტორიალი. 3) მამრავლების ცხრილი (1–9). 4) გამოიცანი რიცხვი (random-ის გარეშე, ფიქსირებული რიცხვით). 5) დახატე „ნაძვის ხე“ ვარსკვლავებით.
