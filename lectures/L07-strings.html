შემოწმება — 9 კითხვა

1. რა განსხვავებაა return-სა და print-ს შორის ფუნქციაში?
return აბრუნებს მნიშვნელობას გამომძახებელს — მისი შემდგომი გამოყენება შეიძლება. print მხოლოდ ეკრანზე გამოაქვს; ასეთი ფუნქცია None-ს აბრუნებს.
2. რას აბრუნებს ფუნქცია, რომელსაც return არ აქვს?
None.
3. რატომ არის def f(a=1, b): შეცდომა?
ნაგულისხმევი მნიშვნელობის მქონე პარამეტრი ბოლოში უნდა იდგეს. სწორია def f(b, a=1):.
4. რას აკეთებს *args და რას **kwargs?
*args აგროვებს პოზიციურ არგუმენტებს tuple-ად; **kwargs — სახელდებულს ლექსიკონად.
5. რას დაბეჭდავს?
x = 10
def f(): x = 5
f(); print(x)
10. ფუნქციაში შექმნილი x ლოკალურია — გლობალურს არ ცვლის.
6. math.sqrt(16) აბრუნებს 4-ს თუ 4.0-ს?
4.0 — math-ის ფუნქციები float-ს აბრუნებენ.
7. რომელი დიაპაზონიდან აბრუნებს რიცხვს random.randint(1, 6)?
1-დან 6-ის ჩათვლით — ორივე კიდე შედის, range-ისგან განსხვავებით.
8. რას აკეთებს random.seed(42)?
აფიქსირებს გენერატორის საწყის წერტილს — მიმდევრობა განმეორებადი ხდება. სასარგებლოა ტესტირებისთვის.
9. რას აბრუნებს def f(): return 1, 2 და რა ტიპისაა?
(1, 2) — ერთი ობიექტი, tuple. შეიძლება დაიშალოს: a, b = f().

წვდომა

ამონაჭერი (slice) — [start:stop:step]

s = "პროგრამირება"

print(s[0:5])     # პროგრ   — 5 არ შედის
print(s[:5])      # პროგრ   — თავიდან
print(s[5:])      # ამირება — ბოლომდე
print(s[:])       # მთლიანი ასლი
print(s[-4:])     # რება    — ბოლო 4
print(s[::2])     # ყოველი მეორე
print(s[::-1])    # შებრუნებული!
ისევ იგივე წესიstop არ შედის — ზუსტად ისე, როგორც range()-ში.
ხერხი, რომელიც უნდა იცოდეs[::-1] — სტრიქონის შებრუნების უმოკლესი გზა. პალინდრომის შემოწმებისთვის აუცილებელია.
დაფაზე დახატე ინდექსების ორი რიგი (დადებითი და უარყოფითი). სლაისინგი ვიზუალურად ბევრად ადვილად ესმით.

ფორმატირება

name = "ნინო"
score = 87.6543
n = 42

print(f"{name} — {score:.2f}")        # ნინო — 87.65
print(f"{score:10.2f}")               # "     87.65"  სიგანე 10
print(f"{name:>12}")                  # მარჯვნივ
print(f"{name:<12}|")                 # მარცხნივ
print(f"{name:^12}|")                 # ცენტრში
print(f"{name:*^12}")                 # ****ნინო****

print(f"{n:05}")                      # 00042
print(f"{1234567:,}")                 # 1,234,567
print(f"{0.256:.1%}")                 # 25.6%
print(f"{255:b} {255:o} {255:x}")     # 11111111 377 ff

print(f"{n = }")                      # n = 42  (გამართვისთვის)

ტექსტის ანალიზატორი

def analyze(text):
    """ტექსტის მოკლე სტატისტიკა."""
    words = text.split()
    letters = sum(1 for ch in text if ch.isalpha())

    print(f"{'სიმბოლოები:':<20}{len(text):>6}")
    print(f"{'ასოები:':<20}{letters:>6}")
    print(f"{'სიტყვები:':<20}{len(words):>6}")
    print(f"{'წინადადებები:':<20}{text.count('.'):>6}")

    if words:
        longest = max(words, key=len)
        print(f"{'ყველაზე გრძელი:':<20}{longest:>6}")


sample = input("ჩასვი ტექსტი: ")
analyze(sample)
