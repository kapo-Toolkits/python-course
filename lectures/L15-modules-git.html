გამეორება · ლექციები 13–14

შემოწმება — 8 კითხვა

1. რა სამ ნაბიჯს ასრულებს for ციკლი შიგნით?
იძახებს iter()-ს იტერატორის მისაღებად → ყოველ ბიჯზე next()-ს → StopIteration-ის დაჭერისას ჩერდება.
2. რა განსხვავებაა yield-სა და return-ს შორის?
return ფუნქციას ამთავრებს; yield მნიშვნელობას აბრუნებს და ფუნქციას „აპაუზებს“ — შემდეგი next() იმავე ადგილიდან განაგრძობს.
3. რა განსხვავებაა [x for x in r]-სა და (x for x in r)-ს შორის?
პირველი სიას ქმნის — ყველა ელემენტი მაშინვე მეხსიერებაშია. მეორე გენერატორია — ელემენტს საჭიროებისას ქმნის, მეხსიერებას თითქმის არ იკავებს.
4. რატომ აბრუნებს list(it) მეორედ ცარიელ სიას?
იტერატორი ერთჯერადია — გავლის შემდეგ ამოწურულია. ხელახლა გავლისთვის ახალი iter() სჭირდება.
5. რას ნიშნავს snake_case, UPPER_CASE და PascalCase PEP 8-ში?
ცვლადები და ფუნქციები · კონსტანტები · კლასები.
6. რა განსხვავებაა linter-სა და formatter-ს შორის?
Linter პრობლემას პოულობს და გაცნობებს; formatter თავად ასწორებს ფორმატირებას. Ruff ორივეს აკეთებს.
7. რას აკეთებს pip freeze > requirements.txt?
ჩაწერს ფაილში მიმდინარე გარემოს ყველა პაკეტს ზუსტი ვერსიებით. აღდგენა — pip install -r requirements.txt.
8. რატომ არის სახიფათო უცნობი პაკეტის დაყენება?
PyPI-ს მოდერაცია არ აქვს, დაყენებისას პაკეტის კოდი შენს კომპიუტერზე სრულდება. სახელის ერთი ასოთი შეცდომა (typosquatting) მავნე პაკეტს გამოიწვევს.

მოდული — უბრალოდ .py ფაილი

ყოველი Python-ის ფაილი უკვე მოდულია. საკმარისია მისი იმპორტი.

"""მათემატიკური დამხმარე ფუნქციები."""

PI = 3.14159


def circle_area(r):
    return PI * r ** 2


def is_prime(n):
    if n < 2:
        return False
    for d in range(2, int(n ** 0.5) + 1):
        if n % d == 0:
            return False
    return True
import mathtools

print(mathtools.PI)
print(mathtools.circle_area(5))
print(mathtools.is_prime(17))

ერთადერთი რჩევააირჩიე საკუთარი პატარა პროექტი და დაწერე. კურსი საფუძველს გაძლევს — უნარი პრაქტიკიდან მოდის. 20 ხაზი დღეში სამ თვეში სრულიად სხვა დონეზე გაგიყვანს.
დაასრულე პოზიტიურად. სთხოვე თითოეულს ერთი წინადადებით თქვას, რა პროექტს დაწერდა — ეს ხშირად ნამდვილ მოტივაციას ბადებს.
