ნაბიჯი 1

Python-ის დაყენება

Windows

  • ჩამოტვირთე python.org/downloads
  • ინსტალაციისას აუცილებლად:
    ☑ Add python.exe to PATH თუ ეს არ მონიშნე — ტერმინალი ვერ იპოვის Python-ს
  • „Install Now“ საკმარისია

macOS / Linux

  • macOS: brew install python
  • Fedora: sudo dnf install python3
  • Ubuntu: sudo apt install python3 python3-pip

რომელი ვერსია?

ნებისმიერი Python 3.10+. კურსში 3.12/3.13 ვგულისხმობთ.

Python 2 არ გამოგადგებაის 2020 წელს გაუქმდა. თუ სადმე ნახავ print "გამარჯობა" ფრჩხილების გარეშე — ეს ძველი კოდია.
Microsoft Store-ის PythonWindows-ზე python-ის აკრეფამ შეიძლება Store გახსნას. ეს ნიშნავს, რომ ნამდვილი Python არაა დაყენებული ან PATH-ში არაა.

ნაბიჯი 1 · შემოწმება

დარწმუნდი, რომ იმუშავა

გახსენი ტერმინალი (Windows: Win+R → cmd) და აკრიფე:

python --version
Python 3.13.1

pip --version
pip 24.3.1 from ...

Windows-ზე ალტერნატივა: py -V · Linux/macOS: python3 --version

„python is not recognized“ / „command not found“PATH არაა მოწესრიგებული. მარტივი გამოსავალი: ხელახლა გაუშვი ინსტალატორი → Modify → მონიშნე Add to PATH. შემდეგ დახურე და ხელახლა გახსენი ტერმინალი.

ნაბიჯი 1 · ბონუსი

REPL — ინტერაქტიული რეჟიმი

უბრალოდ აკრიფე python ტერმინალში — მიიღებ „ცოცხალ“ Python-ს:

>>> 2 + 3 * 4
14
>>> "გამარჯობა" + " " + "მსოფლიო"
'გამარჯობა მსოფლიო'
>>> exit()
რისთვის?სწრაფი ექსპერიმენტისთვის: „როგორ იქცევა ეს ფუნქცია?“ — ფაილის შექმნა არ გჭირდება. კურსის განმავლობაში ხშირად გამოვიყენებთ.
აქ ცოცხლად აჩვენე: მოკლე გამოთვლა, სტრიქონის შეერთება, შემდეგ განზრახ შეცდომა (მაგ. 1/0) — რომ ნახონ traceback-ის სახე.

რატომ VS Code?

უფასო და ღია

კოდი MIT ლიცენზიით. სრულიად ღია ალტერნატივა — VSCodium (ტელემეტრიის გარეშე).

ნაბიჯი 5

სწორი ინტერპრეტატორის არჩევა

ეს ყველაზე ხშირი დაბნეულობის წყაროა. VS Code უნდა იცოდეს, რომელი Python გაუშვას.

  1. Ctrl+Shift+P
  2. აკრიფე Python: Select Interpreter
  3. აირჩიე ვერსია სიიდან (მაგ. Python 3.13.1 64-bit)

არჩეული ვერსია ჩანს ქვედა ზოლში (status bar), მარჯვნივ.

ტიპური სიმპტომი„ბიბლიოთეკა დავაყენე pip-ით, მაგრამ VS Code ამბობს ModuleNotFoundError“ → სავარაუდოდ pip სხვა Python-ში დააყენა, ვიდრე VS Code იყენებს.

hello.py

print("Python-ის კურსი დაიწყო")

ინსტრუმენტი

ჩაშენებული ტერმინალი

Ctrl+` — ხსნის და ხურავს ტერმინალს რედაქტორის შიგნით.

  • რატომ სჭირდება?პროგრამის გაშვება, პაკეტების დაყენება, ვერსიების შემოწმება — ყველაფერი ერთ ფანჯარაში
  • Windows-ზე ორი ვარიანტიაPowerShell (ნაგულისხმევი) და Command Prompt. ორივე გამოდგება — ბრძანებები, რომლებსაც ვიყენებთ, იდენტურია
python hello.py          # პროგრამის გაშვება
pip install requests     # პაკეტის დაყენება
pip list                 # რა მაქვს დაყენებული
cd საქაღალდე             # საქაღალდეში გადასვლა
cls / clear              # ეკრანის გასუფთავება

კარგი ჩვევა

ვირტუალური გარემო (venv)

ცალკე „ყუთი“ თითოეული პროექტისთვის, სადაც მისი ბიბლიოთეკები ცხოვრობს.

# შექმნა (პროექტის საქაღალდეში)
python -m venv .venv

# გააქტიურება — Windows
.venv\Scripts\activate

# გააქტიურება — macOS / Linux
source .venv/bin/activate

# ახლა pip მხოლოდ ამ პროექტში დააყენებს
pip install requests
რატომ?პროექტს A სჭირდება ბიბლიოთეკის 1.0 ვერსია, პროექტს B — 2.0. ერთ საერთო Python-ში ეს კონფლიქტია. venv ამ პრობლემას საერთოდ აცილებს.

დეტალურად — XIV–XV კვირაზე (პაკეტები და pypi). ახლა უბრალოდ იცოდე, რომ არსებობს.

ინსტრუმენტი

გამართვა (debugging) — F5

„print-ებით ძებნა“ მუშაობს, მაგრამ დებაგერი უფრო სწრაფია.

  1. დააწკაპე ხაზის ნომრის მარცხნივ → გამოჩნდება წითელი წერტილი (breakpoint)
  2. დააჭირე F5 → პროგრამა გაჩერდება იმ ხაზზე
  3. მარცხენა პანელში ხედავ ყველა ცვლადის მიმდინარე მნიშვნელობას
  4. F10 ერთი ნაბიჯი · F11 ფუნქციაში შესვლა · F5 გაგრძელება
როდის გამოვიყენოთროცა შედეგი არასწორია, მაგრამ არ ვიცი რომელ ნაბიჯზე გაფუჭდა. → XII კვირა (შეცდომები)
