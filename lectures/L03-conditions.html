წანაცვლებით (indentation) — სტანდარტი 4 ჰარეა. ბლოკს ხსნის ორწერტილი :.

3 1 3.5 — მთელი გაყოფა, ნაშთი და ჩვეულებრივი გაყოფა (ყოველთვის float).
4. რა ტიპს აბრუნებს input()?
ყოველთვის str-ს. რიცხვად გამოსაყენებლად საჭიროა int(input(...)) ან float(input(...)).
5. რას დაბეჭდავს print(2 + 3 * 4) და რატომ?
14. გამრავლებას შეკრებაზე მაღალი პრიორიტეტი აქვს. 20-ის მისაღებად საჭიროა (2 + 3) * 4.
6. რომელი სამი სახელია დაუშვებელი ცვლადისთვის: 2name, _x, my name, class, Age?
2name (ციფრით იწყება), my name (ჰარე), class (რეზერვირებული სიტყვა). _x და Age დასაშვებია.

int(9.99) → 9 (წილად ნაწილს კვეცავს), round(9.99) → 10 (ამრგვალებს).

ორობით სისტემაში 0.1 და 0.2 ზუსტად ვერ ჩაიწერება, ამიტომ ჯამი გამოდის 0.30000000000000004. ეს ყველა ენას ეხება, არა მხოლოდ Python-ს.

თავისებურება

„დამოკლებული“ გამოთვლა (short-circuit)

Python ლოგიკურ გამოსახულებას ბოლომდე არ ითვლის, თუ პასუხი უკვე ცნობილია.

x = 0

# and: თუ პირველი False-ია, მეორეს აღარ შეამოწმებს
print(x != 0 and 10 / x > 1)    # False — გაყოფა არ მოხდა

# or: თუ პირველი True-ია, მეორეს აღარ შეამოწმებს
print(x == 0 or 10 / x > 1)     # True
პრაქტიკული სარგებელიესაა სტანდარტული ხერხი ნულზე გაყოფის ან ცარიელი მონაცემის „ავარიის“ ასაცილებლად — ჯერ ამოწმებ საშიშ პირობას, მერე იყენებ.
კარგი ადგილია ავარიის ცოცხლად საჩვენებლად: ჯერ დაწერე 10 / x != 0 and x != 0 (ავარია), მერე შეაბრუნე თანმიმდევრობა.

== თუ is?

a = [1, 2, 3]
b = [1, 2, 3]

print(a == b)   # True  — მნიშვნელობები ტოლია
print(a is b)   # False — სხვადასხვა ობიექტია

x = None
print(x is None)      # ✓ სწორი სტილი
print(x == None)      # მუშაობს, მაგრამ არასწორი სტილი
წესიis მხოლოდ None, True, False-სთან. დანარჩენ შემთხვევაში — ==.

year = int(input("წელი: "))

if year % 400 == 0:
    is_leap = True
elif year % 100 == 0:
    is_leap = False
elif year % 4 == 0:
    is_leap = True
else:
    is_leap = False

if is_leap:
    print(f"{year} ნაკიანია — 366 დღე")
else:
    print(f"{year} ჩვეულებრივია — 365 დღე")

# იგივე, ერთი ლოგიკური გამოსახულებით:
is_leap = year % 4 == 0 and (year % 100 != 0 or year % 400 == 0)

  • ჯაჭვი 10 < x < 20 და in კოდს კითხვადს ხდის
